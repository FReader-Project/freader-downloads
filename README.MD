# FReader Downloads

The official download hub for FReader releases.

## Get FReader

When a version is available, its release page lists the installers, supported
platforms, and release notes.

[Browse all FReader releases](https://github.com/FReader-Project/freader-downloads/releases)

Desktop builds target Windows, macOS (Apple Silicon and Intel), and Linux.
Availability and package formats are listed with each release.

FReader is actively developed. Check the release notes for known issues and
platform-specific installation guidance.
